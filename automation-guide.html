🐳 Prerequisites: Do You Need Docker?
Executive Decision Guide

Short Answer: Docker is optional. If you are on macOS with Node.js installed, you can run the recorder directly with hardware acceleration in 1 command. However, if you want zero-dependency sandboxing or CI/CD automated pipeline builds, Docker is fully configured and ready.

Recommended (Fastest)

🍎 Native macOS / Local Run

Fastest execution with GPU hardware acceleration, instant screen feedback, and native Google Chrome rendering.

Prerequisites:
  • Node.js ≥ 18 (Installed: v22.22.0)
  • Playwright & Chromium (npm install & npx playwright install chromium)
# 1. Run automated recording
npm run record

# 2. View recorded takes in recordings/
ls -lh recordings/

🐳 Docker Containerized Run

Best for isolated CI/CD cloud runners, Linux servers without GUI, and automated weekly documentation build pipelines.

Prerequisites:
  • Docker Desktop (Started / Running)
  • No Node.js installation needed on host
# 1. Start Docker Desktop, then run:
docker compose up

# Videos are automatically output to ./recordings
⚙️ How the Automation Engine Works Under the Hood
record_shots.js
1

Chromium Browser Viewport & Video Pipe Setup

Playwright launches a headless Chromium instance with a fixed 1920x1080 resolution (1080p @ 60fps) and streams the frame buffer directly to a .webm encoder inside the recordings/ directory.

2

Virtual Animated Cursor Injection (injectVisualCursor)

Because headless browsers do not show the operating system mouse cursor, our script injects a high-visibility SVG pointer (gold body with cyan core and drop shadow) into the page DOM at z-index: 9999999.

3

Smooth Cubic Bezier Motion Interpolation (smoothMove)

Rather than jumping abruptly between coordinates, mouse movements use a Cubic Ease-In-Out interpolation curve (t < 0.5 ? 4*t^3 : 1 - (-2*t+2)^3/2) across 18ms timesteps, giving the pointer natural, professional presenter movement.

4

Click Wave Ripple Physics (rec-click-ripple)

Every click on buttons, form fields, and puzzle blocks triggers a glowing cyan & amber wave that expands from scale 0.4 to 3.8 before fading out, providing clear visual confirmation of interactions in the video.

5

Takes Vault Manifest Generation (takes-manifest.json)

Upon completing all 4 shots, the script renames the video files into standard production naming conventions (video-1.1-shot1-architecture.webm) and writes a complete JSON manifest with durations, byte counts, and timestamps.

📄 Production Code Reference
Ready to inspect

1. Dockerfile

# Automated Video Shot Recorder Container
FROM mcr.microsoft.com/playwright:v1.49.1-noble

WORKDIR /app
COPY package*.json ./
RUN npm ci || npm install
COPY . .
RUN mkdir -p /app/recordings

CMD ["npm", "run", "record"]

2. Docker Compose Configuration (docker-compose.yml)

version: '3.8'

services:
  shot-recorder:
    build: .
    container_name: shotlist-video-recorder
    volumes:
      - ./recordings:/app/recordings
    command: npm run record
